Perfexio needs its Firebase keys

Configuration required

Open public/js/env.js and paste the web app configuration from the Firebase Console into PERFEXIO_FIREBASE_CONFIG.

  1. Firebase Console → project perfexio → Project settings → General.
  2. Under “Your apps”, add a Web App or open the existing one.
  3. Copy apiKey, messagingSenderId and appId.
  4. Paste them into env.js, then reload this page.

These web values are safe to publish. Access is controlled by Firestore security rules, not by hiding the keys. Never place a service account private key in this project.
